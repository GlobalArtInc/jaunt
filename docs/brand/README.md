# Jaunt brand

The mark is an archway with a dot passing through it: access that opens for one person at a time. The wordmark is drawn from rounded strokes of the same weight as the arch, so the arch reads as the same shape as the letters n and u.

## Files

| File | Use |
|---|---|
| `mark.svg` | the mark on its tile, for any size from 16 px up |
| `mark-512.png` | the mark as a bitmap for places that do not take SVG |
| `wordmark-light.svg` | the name in dark navy, for light backgrounds |
| `wordmark-dark.svg` | the name in white, for dark backgrounds |
| `lockup-light.svg`, `lockup-dark.svg` | the mark and the name side by side |
| `lockup-light-256.png`, `lockup-dark-256.png` | the lockups as bitmaps with a transparent background |

The console uses the same mark as its favicon (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png` under `assets/brand`).

## Colours

| Role | Value |
|---|---|
| Tile | `#17143F` |
| Tile edge | `#4A4590` |
| Arch | `#FFFFFF` |
| Dot | `#B7A4FF` |
| Name on light | `#17143F` |
| Name on dark | `#FFFFFF` |

## Rules

- Keep a clear space around the mark of at least a quarter of its width.
- Do not use the mark below 16 px or the lockup below 24 px high.
- Do not recolour the tile, rotate the mark, stretch it, add shadows or outlines, or put the arch on a busy picture.
- Use the light lockup on light backgrounds and the dark lockup on dark ones. The tile edge keeps the mark visible on dark backgrounds.
