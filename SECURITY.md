# Security policy

To report a vulnerability, write to security@example.com. Do not open a public issue for it.

Include the version (`jauntd --version`), what you did, what you expected and what happened. Do not include real secrets or private keys from a production system. We acknowledge a report and say what we will do about it. The trust model and the hardening advice are in [docs/security.md](docs/security.md).

Supported versions: the project has no stable release yet; fixes go to `main`.
